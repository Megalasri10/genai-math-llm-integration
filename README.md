## Integration of a Mathematical Calulations with a Chat Completion System using LLM Function-Calling

### AIM:
To design and implement a Python function for calculating the volume of a cylinder, integrate it with a chat completion system utilizing the function-calling feature of a large language model (LLM).

### PROBLEM STATEMENT:

Large Language Models (LLMs) cannot inherently perform precise mathematical calculations like finding the volume of a sphere because they are language prediction systems rather than calculation engines. This project demonstrates how to overcome this limitation by using OpenAI's Function-Calling mechanism to securely delegate execution to a precise Python function that calculates a sphere's volume \\(\left(V = \frac{4}{3}\pi r^3\right)\\).

### DESIGN STEPS:

#### STEP 1:Define the Core Logic: Create a native Python function sphere_volume(radius) that utilizes the math library to calculate the volume of a sphere accurately.

#### STEP 2:Construct JSON Schema: Build a structural metadata payload defining the function name, description, parameter (radius as a number), and required parameters.

#### STEP 3:Initialize Chat State: Pass the tool specification schema along with the user's conversational prompt (e.g., "Calculate the volume of a sphere with radius 5") to the Chat Completions endpoint.

#### STEP 4:Intercept Tool Arguments: Extract the arguments generated by the model using json.loads(), retrieve args["radius"], and execute the local Python calculation function.

#### STEP 5:Generate Final Context: Append the mathematical execution results back to the conversation thread using the tool role and the corresponding tool_call_id, then call the model again to generate a friendly response.

def sphere_volume(radius):
    """Calculate the volume of a sphere"""
    volume = (4 / 3) * math.pi * radius ** 3
​
    return json.dumps({

        "volume": round(volume, 2),
        "unit": "cubic units"
